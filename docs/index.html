TRAP: Tool-result Replay Attack for Probing Misbinding in LLM Agents

A real tool result can be unsafe in an incompatible execution context.

Yutong Zhi1 · Jie Zhang2 · Xiuqi Lu1 · Jiayuan Xu1 · Jing Shao2

1Tsinghua University   2Shanghai AI Laboratory

PaperCode & benchmark

Abstract

Correct data, incorrect context

As agents use caches, queues, checkpoints, and recovery paths, tool results can outlive the execution that produced them. TRAP characterizes tool-result misbinding: a real, unmodified result is consumed in a context where it is no longer valid. ReplayBench uses controlled replay to study how that association error propagates from delivery to wrong action and persistent final-state error.

Across its evaluated settings, the paper finds widespread failures and shows that runtime validity checks can block them while preserving legitimate recovery.

Distinct from prompt injection. The replayed result contains no added adversarial instruction. The failure comes from associating authentic evidence with the wrong execution context.
